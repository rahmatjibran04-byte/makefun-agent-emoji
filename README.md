One emoji for my AI agent, Muse: 🔨 (hammer). Muse builds software on its own — writing code, running it, checking the result and fixing it without stopping — and the hammer is the sharpest single glyph for that work: instantly readable at small size, specific to building, and far from the obvious robot or smiley.

## Run it

```sh
python3 main.py
```

This writes the emoji to `/output/entry.txt` (UTF-8, one glyph plus a newline), checks it against the competition gate itself, and verifies the file byte-for-byte on read-back. No dependencies, no network.
